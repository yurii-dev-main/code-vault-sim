# 🪙 Інтерактивна 3D-банка з монетами (Interactive Reward Jar)

Вебзастосунок із 3D-банкою нагород, фізикою WebGL (Three.js + Rapier3D WASM), кришкою, що відкручується, монетами двох номіналів (1 та 2 бали), інтерактивним перетягуванням і кидком монет, інспекцією нагород та зручним графічним редактором даних.

---

## 🚀 Швидкий старт

### 1. Запуск у режимі розробки:
```bash
npm run dev
```
Після запуску відкрийте у браузері:
- **3D-банка з монетами:** [http://localhost:5173/](http://localhost:5173/)
- **Редактор даних монет:** [http://localhost:5173/editor.html](http://localhost:5173/editor.html) (також доступний за кнопкою у верхньому правому куті 3D-сцени)

### 2. Збірка для публікації (Production):
```bash
npm run build
```
Готові статичні файли буде збережено у папку `dist/`.

## 🎮 Можливості та керування в 3D

1. **Відкручування кришки:**
   - Клікніть або торкніться пальцем кришки банки.
   - Кришка зробить плавні оберти, відкрутиться по різьбі та з фізичним імпульсом відлетить на підлогу поруч із банкою.
2. **Перетягування та кидок монет (Drag & Throw):**
   - Затисніть монету лівою кнопкою миші або пальцем і потягніть її вгору з банки.
   - Якщо монета всередині банки — вона притискається до скла зсередини, не пробиваючи стінки.
   - Коли витягуєте монету назовні — вона плавно підтягується на оптимальну відстань перед камерою для зручного огляду.
   - При різкому відпусканні монета отримує імпульс швидкості та обертання, реалістично розлітаючись по підлозі.
3. **Звуковий супровід та затишна фонова музика:**
   - **Фонова музика:** процедурний теплий ембієнт із розслаблюючими акордами та мелодією дзвіночків без жодних зовнішніх аудіофайлів (Web Audio API).
   - **Фізичні звукові ефекти:**
     - Дзвін металевих монет при падінні, пересипанні та ударах.
     - Характерний звук відкручування різьби кришки та механічний клік під час її відльоту.
     - Металевий глухий звук удару кришки об підлогу.
     - Звук захоплення монети та розсікання повітря при кидку.
   - **Кнопка «🎵 Музика»** у верхньому правому кутку дозволяє миттєво вмикати або вимикати музику.
4. **Інспекція монети (Картка нагороди):**
   - **На комп'ютері:** Подвійний клік ЛКМ або клік ПКМ по будь-якій монеті.
   - **На смартфоні:** Швидкий подвійний тап по монеті.
   - Відкриється картка з інформацією: **Кому вручено**, **За що**, **Номінал** (1 або 2 бали) та **Дата вручення**.
5. **Обертання камери:**
   - Затисніть вільну область екрана мишею або пальцем для обертання навколо банки (`OrbitControls`).
6. **Кнопка «Повернути в банку»:**
   - Миттєво закручує кришку назад на банку та заново акуратно насипає всі монети всередину.

## 🔒 Приватний доступ до редактора даних монет (`editor.html`)

Кнопку редактора прибрано з публічного інтерфейсу 3D-банки, щоб доступ був лише у вас:
1. **Пряме посилання в браузері:**
   - [http://localhost:5173/editor.html](http://localhost:5173/editor.html) (або `https://ваш-домен.pages.dev/editor.html`)
2. **Секретна комбінація клавіш:**
   - Натисніть **`Ctrl + Shift + E`** (або **`Cmd + Shift + E`** на Mac) у будь-якому місці 3D-сцени.
3. **Секретний жест:**
   - Потрійний швидкий клік по верхній плашці балансу («Всього балів»).

### Можливості редактора:
- **Швидке введення ключових полів:**
  - **Хто отримав:** ім'я студента / одержувача
  - **За що:** завдання, проєкт, активність
  - **Номінал:** 🥈 1 бал (срібна монета) або 🪙 2 бали (золота монета)
  - **Коли:** дата вручення (за замовчуванням сьогоднішня, є кнопка «Сьогодні»)
- **Таблиця з пошуком і фільтрацією:**
  - Живий пошук за ім'ям, завданням або датою
  - Редагування будь-якого запису за кліком на ✏️
  - Видалення запису за кліком на 🗑️
- **Збереження:**
  - Кнопка **«💾 Зберегти»** — у dev-режимі миттєво перезаписує `public/coins.json` на диску.
  - Кнопка **«📥 Завантажити JSON»** — завантажує файл `coins.json`.
  - Кнопка **«📤 Імпортувати»** — дозволяє імпортувати готовий файл `coins.json`.

## 🌐 Деплой на Cloudflare Pages

Проєкт повністю **Zero-backend**:
1. Підключіть репозиторій у Cloudflare Pages Dashboard.
2. Вкажіть параметри збірки:
   - **Framework preset:** `Vite`
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
3. Файл `public/_headers` автоматично передасть необхідні заголовки `Cross-Origin-Opener-Policy: same-origin` та `Cross-Origin-Embedder-Policy: require-corp`, необхідні для WebAssembly-фізики Rapier3D.
